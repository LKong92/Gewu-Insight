# User Guide screenshot inventory

Edition: September 9, 2026. Both HTML and PDF use these 32 packaged PNG captures.

## Capture rules

- Capture the original Gewu Insight App through native window capture. Do not use generated or fixture screenshots as manual illustrations.
- Capture only the intended window or dialog bounds. Exclude Computer Use overlays, sharing indicators and other applications. Close unrelated settings before opening the next one.
- Preserve the existing classified Library example, Hong Ding Author Monitor and Nature Journal Monitor with figures.
- Browser uses the fully loaded Nature Physics PDF at https://www.nature.com/articles/s41567-026-03429-7.pdf. Save to Gewu Details visibly confirms the existing Gewu Key, DOI, PDF Ready and Published version. The review was canceled without importing.
- Credential fields stay masked. The AI form shows permissions without creating a connection, revealing a token or changing an existing grant.
- Screenshots record real saved preferences, files and bookmarks. The Author add form honestly shows the existing local Scholar pause; its caption distinguishes that state from the input workflow.

## Coverage and limits

All standalone settings panels are illustrated, including both AI connection states. Loader import, metadata refresh and missing-identifier modes are illustrated separately. The Library picker, Shortcut/Space forms, Subject/Author forms, Browser Home/PDF and both Save review states, built-in PDF/Markdown Quick Look, About and Help windows are covered.

Naming Rule is a menu choice, not another settings window. Its options remain documented in text. Generic macOS open/save dialogs, transient progress and destructive confirmations are not an exhaustive state gallery; no deletion, import, broad refresh or token creation was performed merely to make an illustration. A native folder chooser could not be captured reliably and is not represented by a fabricated image.

The PDF builder constrains screenshot width and height while preserving aspect ratio. Product Identity chapters 4-1 through 4-4 retain continuous flow. New captures must be added to the builder route map and the guide asset inventory check.
