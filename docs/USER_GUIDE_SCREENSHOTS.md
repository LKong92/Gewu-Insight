# User Guide screenshot inventory

Edition: September 16, 2026 · Version 1.0.0 / Build 1. HTML and PDF use the same 35 packaged PNG captures.

## Capture rules

- Capture the real original Gewu Insight App. Do not use generated UI, test fixtures, painted-out indicators or substituted data as manual illustrations.
- Main-workspace screenshots retain all six top navigation tabs. Native fullscreen window capture excludes Computer Use badges and cursor halos without cutting off the navigation.
- Standalone windows and dialog illustrations use their own bounds. Cropping may remove surrounding desktop, blurred page edges and system title-bar overlays; it must not remove controls needed to explain the illustrated workflow.
- Library uses an existing paper with Published version and Preprint files, including its real Default. Author Monitor uses Hong Ding. Journal Monitor uses Nature with figures. The empty Add Monitored Author form contains no stale network-pause message.
- This revision captures changed interfaces only: Space heading, table sorting, Shortcut path, Browser and Home tab alignment, and compact/expanded Save to Gewu. The 28 unchanged illustrations remain. Settings panels were captured on September 13 and retained after review; they were not recaptured this time.
- Browser shows the fully loaded public Nature Physics PDF at https://www.nature.com/articles/s41567-026-03429-7.pdf with the bookmark sidebar open. Home separately shows Favorites. The user expressly authorized displaying their real bookmark/Favorites names in the User Guide and its GitHub delivery. Bookmark destination URLs, credentials and account contents are not shown.
- Compact and expanded Save to Gewu review states use the same existing paper. The review is canceled; no Library import is performed. These captures show the current flat panel, existing Gewu Key correction and Use Loaded PDF control.
- Saved source credentials remain masked. AI Access shows existing scope and the blank New Connection form without revealing a token, creating a grant or changing permissions.
- Screenshot navigation does not import, delete, classify or refresh papers, change saved preferences, or start/pause the user’s background refresh. The user resumed that task during the audit; no App restart is needed for this documentation update.

## Coverage and limits

Settings coverage includes Open Source, arXiv Scope, Fields, Quick Look, Add to Library, Website Links, AI Access, PDF Rename and Font Size. Loader import, Refresh Info and missing-identifier modes are illustrated separately. Shortcut/Space and Subject/Author forms, the destination picker, Browser Home/PDF and both save-review states, PDF/Markdown Quick Look, About and Help are also covered.

Twenty-eight unchanged illustrations remain after review, including four from September 9, as individually dated above. Five existing images were replaced and two were added. The seven new captures use the user-authorized Core Graphics window API; dialog images retain their full bounds without altering their contents. Main-window captures are uncropped and retain all six top tabs. Naming Rule is a menu choice, not a separate settings window. Generic macOS file choosers, transient progress and destructive confirmations are not an exhaustive state gallery.

The PDF builder preserves image aspect ratios and constrains both width and height. Product Identity chapters 4-1 through 4-4 flow continuously, with numbering and links intact. The automated guide checks cover the route map and complete asset inventory; visual inspection covers the actual PNGs and generated PDF.
