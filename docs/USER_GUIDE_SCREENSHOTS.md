## Capture rules and this revision

- Use only the real original Gewu Insight App, never generated UI, test fixtures,
  substituted research data, stitched states, or painted-out overlays.
- Main-window figures keep all six navigation tabs. The two new main-window
  images use native fullscreen capture, with no cropping or Computer Use halo.
- Settings figures keep the complete visible dialog bounds. Cropping removes
  only the blurred surrounding workspace; scrolling is normal live App scrolling.
  New Connection is its upper view; lower collections, expiry and Create Connection
  are reached by scrolling. The caption states that boundary explicitly.
- The Library overview retains its already-classified Published version and
  Preprint with real Default. The table example is an existing Space paper with
  Published version and Summary. No classification was changed for a picture.
- Author Monitor retains Hong Ding; Journal Monitor retains Nature with figures;
  Add Monitored Author remains empty and free of stale red Scholar-pause text.
- Replace library-table.png for Time added; markdown-quick-look.png for readable
  Properties and Source record; ai-new-connection.png for optional write access.
  Add ai-write-permissions.png for saved operations, root selections and feedback.
- Retain orientation and Space-heading illustrations for their stated purpose;
  their incidental dates/older table columns are not the current-feature reference.
  The dedicated Table View figure supplies the complete current five-column view.
- The existing Browser/Favorites names were expressly approved by the user for
  the guide and GitHub. No credentials, bookmark destination lists or tokens are
  exposed. Saved source credentials remain masked in retained Settings images.
- AI screenshots show the existing connection and a blank form. No permissions
  were changed or saved, and no connection was created or revoked. The selected
  write roots illustrate this connection only, not recommended default access.
- No import, deletion, file edit, provider refresh or background task change was
  performed. App navigation was restored after capture; no restart was needed.
