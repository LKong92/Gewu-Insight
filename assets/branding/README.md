# Branding artwork

## Seal-style motif

`GewuSealGlyphs.png` was generated with AI assistance for Gewu Insight and
selected by the user on October 10, 2026. It reads 格物洞見 down the right column
and then down the left. A text-generated concept was refined using that same
AI-generated image to square the stroke ends and reduce the surrounding whitespace.
Production preparation only removed the white background and recolored the strokes,
keeping their positions and proportions. The application uses light gray with its
existing low display opacity. The guide PNG preserves the same alpha channel in
black for the PDF; the HTML guide applies the equivalent black tint. Both manual
formats show the motif without a background panel.

[The provenance record](GewuSealGlyphs.provenance.json) contains the generation
prompt, selected-preview and production hashes, and the approved pixel
conversion. It records the creation process, not legal clearance, a
copyright-free status, or exclusive rights.

The current source and newly prepared macOS resources use this motif. Existing
GitHub installers and the separate Windows branch require their own updates;
changing this file does not replace those distributions.

## About wordmark

`GewuAboutCalligraphy.png` is a modern assembly of character images attributed
to Zhu Yunming (祝允明, 号枝山). The selected 洞 form has been matched visually
to 客有吹洞簫者 in his 草书前后赤壁赋卷, held by the Shanghai Museum:
[collection record](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/CI00000383).
The original works for 格, 物 and 見 have not yet been established. The User Guide
cites the identified historical work and states those gaps; it no longer links
to a character-dictionary website. The production artwork itself is unchanged.

The museum citation identifies the historical work, not a new claim about where
the production file was downloaded. Acquisition references and comparison
images are retained in the ignored local research archive. Original authorship,
the modern assembly and any independently protected modern reproduction must
be considered separately; the software license does not settle external rights.
